# Student Management System

## Project Description
A simple C++ application used to manage student details and academic records.

## Technologies Used
- C++
- Vector
- Structures
- Loops and conditional statements

## Features
- Add student details
- View student records
- Search for a student by ID
- Update student information
- Delete student records

## How to Run
1. Download or clone this repository.
2. Compile student.cpp using a C++ compiler.
3. Run the compiled program.

## What I Learned
- Organising data using structures
- Using vectors to store records
- Implementing CRUD operations
- Applying loops, conditions and searching
